Why backit?

Maestral, a popular open-source Dropbox client, is no longer maintained — leaving people who relied on it without a reliable way to keep a local copy of their Dropbox contents. backit isn't a sync client. It uses rclone to talk directly to the Dropbox API and mirror your files down to a local backup volume on a schedule — one dependable local copy of your Dropbox.

⚠ This is a backup, not a synced folder

rclone copies one-way, from Dropbox down to the local volume. Don't create, edit, or delete files directly in the local backup copy — nothing you do there is sent back to Dropbox, and any changes will be silently overwritten or deleted on the next run to match whatever is currently in Dropbox. Make your real edits in Dropbox itself.

What it does

One job, done carefully.

🖴

Dropbox to local drive

rclone mirrors your Dropbox down to a folder on a local backup volume.

⏱

Smart scheduling

Reminder, final pre-backup check, and backup time are all configurable — with computed times shown live.

⏻

No Dropbox app needed

rclone talks directly to the Dropbox API — no Dropbox desktop client has to be installed or running.

▤

Live progress

Byte counts, transfer rate, and elapsed time update as each backup runs, right in the main window.

🕓

Run history

Every run and its result is recorded to a local SQLite database.

✓

Post-sync verification

An optional rclone check after each Dropbox sync surfaces drift between source and destination.

◐

Headless scheduled runs

A LaunchAgent triggers a background run once a day at your configured time — no window required.

⏭

Skip a night

One click in a notification (or in Settings) defers tonight's run if you're not ready.

⚠

Disk-missing detection

backit skips silently and notifies you if the backup drive isn't connected at run time.

Requirements

  • macOS 26.2 or later
  • rclone — with a Dropbox remote already configured (brew install rclone)

Installation

No signed releases yet — build from source with Xcode:

git clone https://github.com/joemcmahon/backit.git
cd backit
xcodebuild build -project backit.xcodeproj -scheme backit

Then copy backit.app to /Applications/ and launch it.
